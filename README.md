# KantinGo by Muhammad Rizky

[![Deploy to Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/mrizkymxx/KantinGo)

KantinGo adalah aplikasi web modern untuk memesan makanan di kantin kampus. Dirancang dengan UI yang intuitif dan responsif, memungkinkan mahasiswa dan penjual kantin berinteraksi dengan mudah.

![KantinGo Preview](https://via.placeholder.com/800x400/10b981/ffffff?text=KantinGo+App+Preview)

## ✨ Fitur Utama

### Untuk Mahasiswa:
- **Browse Menu**: Jelajahi berbagai kantin dan menu makanan dengan gambar dan harga.
- **Keranjang Belanja**: Tambah item ke keranjang, lihat subtotal, dan proses pembayaran.
- **Pembayaran QRIS**: Simulasi pembayaran menggunakan QRIS untuk kemudahan.
- **Tracking Pesanan**: Pantau status pesanan dari diterima hingga siap diambil.
- **Riwayat Pesanan**: Lihat pesanan sebelumnya.

### Untuk Penjual Kantin:
- **Dashboard Pesanan**: Kelola pesanan aktif dan siap diambil.
- **Update Status**: Ubah status pesanan dari diterima ke disiapkan ke siap diambil.
- **Real-time Updates**: Interface yang responsif untuk operasi harian.

## 🏃‍♂️ Cara Menjalankan Lokal

1. **Clone Repository**:
   ```bash
   git clone https://github.com/mrizkymxx/KantinGo.git
   cd KantinGo
   ```

2. **Jalankan Server Lokal**:
   - Menggunakan Python:
     ```bash
     python -m http.server 8000
     ```
   - Atau gunakan server HTTP lainnya (misalnya Live Server di VS Code).

3. **Buka di Browser**:
   - Akses `http://localhost:8000/login.html` untuk mulai.

## 🌐 Deploy ke Vercel

1. Buka [Vercel](https://vercel.com) dan login.
2. Klik "New Project".
3. Import repository GitHub: `mrizkymxx/KantinGo`.
4. Deploy otomatis – Vercel akan detect sebagai static site.
5. Dapatkan URL live (misalnya `https://kantingo.vercel.app`).
